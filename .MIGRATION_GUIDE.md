# Migrate from v1


## endpoint old -> new

* elements/count -> stats/features/count
    * for non-polygon relations: not available atm, maybe eventually as `stats/collections/count`
* elements/length -> stats/features/length
* elements/area -> stats/features/area
* contributions/count -> stats/contributions/count
* contributions/latest/count ~> stats/currentness/count
* users/count -> stats/contributors/count

* elements/geometry -> extraction/features.parquet
* elementsFullHistory/geometry -> extraction/features.parquet

* contributions/geometry -> extraction/contributions.parquet


groupBy/tag -> parameter for `stats/features/…`
    ```json
    "groupBy": {
        "type": "byTag",
        "key": "…"
    }
    ```
groupBy/key -> multiple requests
groupBy/boundary -> multiple requests
groupBy/type -> multiple requests

* `elements/…/density` -> calculate on client side
* `elements/…/ratio` -> two requests + calculate on client side
* `elements/perimeter` -> not available, contact us
*  - " - also `contributions/count/*`

* `users/groupBy/tag` -> not yet

* extraction: `*/controid` -> not yet, do on client side
* extraction: `*/bbox` -> bbox included, do on client side

* metadata -> metadata


## request structure

* no get requests for stats
* GET requests for extraction limited to bboxes
* parameters as JSON instead of form-urlencoded
* bcircles -> not available, construction client side
* bboxes -> only single bbox
* bpolys -> only single geojson geometry object (no feature collection) or WKT
    for multiple -> multiple requests
* uneven time interval (list of timestamps) -> not yet implemented
* clip parameter: also available on stats/features (recommend to use clip=yes for small queries)


## changed result formats

* stats: columns layout for json responses (instead of row based format; csv still has row format)
    * examples before/after
* extraction: no geojson, instead parquet (convert on client)

## new stuff

* extraction for relations: 
  `extraction/collections`, `extraction/collections_members`
* filter/validation
* changeset tags on contribution extraction
* health
* parquet format
* more frequent updates

## filter

* squaredness/roundness -> not avaialble anymore
* geometry:other -> geometry:collection
* no more `perimeter: (…)`
* wildcard maches for tag values, e.g. `name ~ *street`, `name ~ "Ma in"*`
    -> TODO: https://docs.ohsome.org/ohsome-api/staging/reference/filter.html
* `geometry.vertices` etc. -> not yet implemented
